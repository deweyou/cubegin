# Cube solvers

[![English](https://img.shields.io/badge/English-blue)](README.md) [![中文](https://img.shields.io/badge/%E4%B8%AD%E6%96%87-blue)](README_ZH.md)

`cubegin-solver` provides full solutions for 2×2, 3×3, 4×4, Pyraminx, Skewb, Square-1 and FTO. Clock uses inverse notation. Auxiliary searches cover goals such as Cross and EOline.

See [solver data provenance](data/README.md) and the [SDK examples](../../docs/sdk.md).
