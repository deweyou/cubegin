# 魔方求解

[![English](https://img.shields.io/badge/English-blue)](README.md) [![中文](https://img.shields.io/badge/%E4%B8%AD%E6%96%87-blue)](README_ZH.md)

`cubegin-solver` 支持二、三、四阶魔方、Pyraminx、Skewb、Square-1 和 FTO 的完整求解。Clock 使用逆公式。辅助搜索支持 Cross 和 EOline 等目标。

参见[求解数据来源](data/README_ZH.md)和 [SDK 示例](../../docs/sdk.md)。
