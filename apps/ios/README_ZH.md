# Cubegin iPhone 和 iPad App

[![English](https://img.shields.io/badge/English-blue)](README.md) [![中文](https://img.shields.io/badge/%E4%B8%AD%E6%96%87-blue)](README_ZH.md)

Cubegin 是原生 SwiftUI 魔方速拧计时器，支持 iOS 和 iPadOS 26 及以上版本。界面跟随系统浅色和深色外观，适配横竖屏及可调整大小的 iPad 窗口。

## 功能

- **计时和训练**：用触屏或实体键盘计时。从 16 类标准项目和 94 类训练中选择，并查看打乱公式和展开图。
- **计时显示与手动录入**：在 **设置 → 计时** 选择实时、到秒或仅观察，停止后仍显示三位小数。把成绩产生方式切为手动后，点计时页输入分、秒和毫秒，也可以标记 +2 或 DNF。
- **轻扫手势**：计时页待机时，默认左扫生成新打乱，右扫确认删除当前分组的最新成绩。可在 **设置 → 计时 → 手势** 为任一方向更换动作、改为手动输入成绩或设为「无」。
- **辅助公式**：点计时页的 ✨，选择当前项目的还原方法。每个项目和成绩分组会记住上次选择，以及备选解法的拖拽顺序。训练模式支持简单十字、简单 XCross 和 F2L 训练的专项提示。
- **成绩庆祝**：当前分组首次取得有效成绩，或刷新单次、Ao5、Ao12 个人纪录时，计时页会撒花。成绩符合条件时，可以点成绩操作区的礼花按钮重播。
- **成绩与统计**：分组管理成绩，标记 +2 或 DNF，查看单次成绩、滚动平均、趋势和用时分布。
- **设置**：选择应用语言和主题、调整计时启动延迟，或开关计时触感。
- **DCTimer 导入**：打开 **设置 → 导入 → 从 DCTimer 导入**，在文件中选择 `spdcube.sqlite`。可以预览成绩、选择导入的分组，也可以撤销最近一次导入。

可选的 WCA 观察支持 8 秒和 12 秒语音报时，并自动记录观察超时判罚。进入观察和从观察开表都在松手时生效，无需等待设置的长按时长。

iPhone Duo 半展开竖屏时，上半屏显示打乱公式和时间，在下半屏操作开停表。

使用支持 iCloud 键值存储的签名时，应用设置会在登录同一 iCloud 账号的设备之间同步。

在 **设置 → 关于** 长按设备 ID 可复制。首次打开时可以选择是否共享诊断和使用数据。你可以在 **设置 → 关于** 更改选择或查看[隐私政策](Cubegin/PrivacyPolicy.md)。成绩明细保存在设备上。
