# App 架构

CubeginApp 是 SwiftUI 入口；LaunchRootView 叠加一次性冷启动动画；AppTabsView 拥有
首页、成绩和设置导航，ContentView 负责首页响应式布局、系统玻璃控件和计时交互。
TimerModel 是 MainActor 上的 Observable 产品状态，Engine 是后台 SDK 适配层。

Engine 封装生成打乱和获取 SVG。Rust 拥有魔方语义，App 不复制
移动规则、打乱算法或求解器。App 的引擎依赖是根目录 Swift Package 的 Cubegin 产品。

计时以 ContinuousClock 计算时长，TimelineView 刷新显示；进入非 active 状态会取消
当前计时且不保存。按住屏幕或空格达到设置中的延迟后，进入计时布局并显示绿色「松开开启」，松开立即在原位开始计时。触摸时可滑入顶部取消区，中央显示红色「松开取消」。滑出后恢复开启提示，松手位置决定开启或取消。
再次按下即停止。计时页默认保持常亮，可在计时设置关闭。关闭后，观察和正式计时期间仍阻止自动锁屏。切离计时页或 App 失去前台活动状态时恢复系统自动锁屏。

开启 WCA 观察后，第一次按下立即显示「松开开启」，松手进入观察，中央从 0 秒正数。观察超时显示
+2 或 DNF。再次按住达到启动延迟后读数变绿。上滑进入顶部取消区后读数变红，
在区内松手只取消起表，观察继续。区外松手以单调时钟判定罚时，满 15 秒为 +2，
满 17 秒为 DNF。盲拧跳过观察，训练需单独启用。观察报时可关闭或选择男女声，
跟随 App 语言，以观察开始后第 8 秒和第 12 秒为发声目标。音频去除开头静音并预先调度，补偿当前输出延迟。音源由 Kokoro-82M 合成，
使用 zm_yunyang、zf_xiaoxiao、am_michael 和 af_heart。
[音色来源](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md)

Solve 保存 UUID、秒数、项目、打乱、日期。成绩以 JSON 原子写入 App Documents 的
solves.json，读取与写入失败通过界面提示。存储包含 solves 与 groups，写入时整体原子替换。
读取兼容原有的成绩数组，缺少 groupID 的记录按项目归入初始分组；缺少罚时字段视为正常。
每个标准项目和完整训练 ID 都有自己的初始分组。用户可新建、重命名并设置默认分组，
同一项目只有一个默认分组。项目切换进入默认分组，当前分组切换只影响保存位置和成绩筛选。
分组选择使用 Sheet，标题居中并提供新增入口，列表支持拖拽排序和左划后在右侧显示编辑、删除。
新建与编辑在同一面板的导航栈内完成，可修改名称和默认设置。名称单行输入，最多 16 个字符，超限时提示并禁用保存；分组选择胶囊和列表名称统一单行显示，超长时尾部省略，旧长名称读取时保持完整。默认组禁止删除，
其余组删除前确认成绩数量并提示无法恢复；确认后整体原子删除该组及其成绩。
成绩详情按 UUID 从模型读取实时值，用右对齐的 +2、DNF 两个紧凑按钮修改判定，互斥选中并可再次点击取消，右上角提供删除并二次确认。成绩、判定按钮组成独立 Section，详情不额外显示原始计时，项目/分组/日期另为一组；判定行去掉额外上下 inset，保留 44pt 点击高度。支持通过下拉菜单移动到同项目其他分组（无目标时不可点击，不提供新增）。独立的详情导航不会因移动离开当前列表而退出。打乱文本与打乱图合并在同一 Section，不显示额外标题，底部复用 SVGView 并将图像水平、垂直居中；iPhone 竖屏和 iPad 的计时页将图像放在右下角。Engine 在后台按该成绩保存的项目/打乱调用 SDK evaluateEvent 生成打乱图，加载失败显示提示。
分组顺序与成绩一并持久化，旧成绩通过初始组 ID 参与筛选及删除。
关闭分组列表的整行拖拽交互，仅右侧拖拽柄的 UIKit 长按手势可发起原生交互排序，
通过 List.onMove 保存结果；长按名称不调序，拖拽取消不写入顺序。
停止后可对刚完成的成绩加 2 秒、标为 DNF 或删除；两种标记互斥，可再次点击撤销。
罚时单独存储，保留原始秒数，成绩列表和详情显示判定结果，原始秒数仍保存在记录中。当前没有云同步。

设置的「导入」二级页列出外部计时器。DCTimer 导入通过系统文件选择器读取 iOS 的
`spdcube.sqlite`，按分组打乱 ID 映射到 Cubegin 项目，在后台通过 SDK 校验打乱。
不匹配的分组和不兼容的成绩分别计数，`2-7` 归入分组不匹配。魔表公式末尾独立的旧版拨针标记在校验和保存前移除。
预览默认按原分组新建，也可追加到各项目的默认分组。确认后成绩、分组和本次新增成绩的 ID 一并原子写入。设置的「导入」页可撤回最近一次新增的成绩，无时间限制。
撤回入口显示导入来源和时间，旧批次没有时间记录时只显示来源。撤回按 ID 移除仍存在的成绩，分组保留。新增为 0 条、取消或失败的导入不会替换可撤回的批次。
成绩日期按设备当前时区解释，源成绩 ID 和原始记录信息生成可重复的 UUID，用于避免重复导入。
设置的「清空成绩」页只列有成绩的分组，支持清空所选分组或全部成绩。确认页等待五秒后才能删除。切出设置标签时重置导航路径。
打乱可解析只说明公式与魔方兼容，无法区分使用相同公式的项目。

平均视图按当前分组的计时顺序生成完整滚动窗口，提供 mo3、ao5、ao12、ao50、ao100、
ao500、ao1000、ao10000。mo3 保留全部成绩。ao 的最快与最差两端各裁剪 5%（向上取整）。
+2 以加罚后的用时计入，DNF 排在最差一端。保留部分含 DNF 时，平均为 DNF，省略 σ。
有效平均的 σ 为保留部分的总体标准差。最快与最差单次取自整个窗口。
平均详情以窗口最新成绩的 UUID 定位，读取当前分组的实时记录，单次沿用原成绩详情导航。
[csTimer 默认裁剪规则](https://github.com/cs0x7f/cstimer/blob/master/src/js/stats/timestat.js) ·
[DCTimer 平均与 σ](https://github.com/MeigenChou/DCTimer-Android/blob/master/app/src/main/java/com/dctimer/util/Stats.java)

SVG 由 Rust 生成，App 使用禁止 JavaScript 的 WKWebView 显示。开始计时后在后台预取
下一条打乱及 SVG，两个 WebView 交替显示和预加载。停止计时后保留上一张图，直到新图
加载完成。打乱公式等待超过 250 ms 才显示「生成中…」。原生渲染和控件归
产品负责。首页计时页固定在一屏内。成绩概要包括有效成绩次数与总次数、总平均、最好单次及当前 mo3、ao5、ao12。iPhone 竖屏和 iPad 在底部并排显示成绩概要和打乱图，概要按图像实际显示高度缩放。

iPad 各项目共用打乱字号上限。默认动态字体下，打乱区域宽度从 600pt 增至 1200pt 时，上限从 20pt 逐步增至 32pt。高度不足时缩小字号，标准五魔也会检查最长一行的宽度以保留七行排版。

首页、成绩和统计、设置、成绩详情和分组编辑共享同一淡青至靛蓝的渐变背景，列表隐藏系统滚动背景以透出渐变。

iPhone 横屏的计时首页按 55/45 分成左右两栏。左栏的公式和打乱图上下居中分布，图文间距按剩余高度在 16–48pt 之间调整。右栏从上到下
显示计时数字、停表操作和双列成绩概要。系统安全区内左右各留 8pt，两栏间距为
16pt。成绩概要与右侧导航底对齐，顶部右侧控件与成绩页标题区的右边界对齐，预留右侧导航列。开表时数字滑到屏幕正中央，
停表后回到右栏。其他内容在计时中隐藏，
左右两侧均可点按停表。启用「减少动态效果」时，数字留在右栏原位。
iPad 计时页用满可用宽度，左右各留 24pt。iPhone 计时页内容宽度上限为 880pt。维护时需检查字体放大、VoiceOver、系统深浅色及降低透明度效果。

## 冷启动

CubeginApp 在进程内持有 hasFinishedLaunch，不写入磁盘。当前按进程重启播放一次，
不加时间间隔限制；系统回收或用户划掉后的新进程都会播放，正常后台恢复不播放。首次显示时，LaunchView 在
系统深浅色背景上展示 80pt 原生四色标志：蓝块按原版缓动旋转 0→378°（1.1 秒），
再用 0.22 秒淡出。标志下方间隔 16pt 放置 108pt 宽的原版 SVG 字标，整体按完整窗口居中。
字标由 Asset Catalog 随系统深浅色自动切换为深色或白色。黄红绿保持静止，蓝块在
前景。图形比例、圆角和颜色来自历史 SVG。

开屏先独立渲染，旋转期间不创建计时页。旋转结束后保持最终姿态，再创建计时页和读取成绩，
页面出现并留出 80ms 布局时间后淡出；淡出完成才启动后台打乱及后续 WebView 加载。
开屏结束前禁用计时页交互并隐藏其辅助功能元素，避免页面初始化打断旋转。
后台返回不重播，开屏中进入后台则直接结束，避免回来继续等待。开启减少动态效果时
显示静止 18° 姿态并短淡出。系统先显示 LaunchScreen.storyboard，布局和蓝块 0° 姿态匹配动画首帧；
它使用 Asset Catalog 的 @3x PNG（字标含深浅色变体），无需等待 SwiftUI 或 SDK 初始化。
动画页仍用原生矢量 Logo 和 SVG 字标。两页都按完整窗口居中，避免安全区差异导致位置跳变。
工程显式声明横竖屏方向；iPad 还支持倒置竖屏，系统启动页与 SwiftUI 保持一致。

Debug 构建可传入 `--hold-launch-screen`：静止在最终 18° 姿态供视觉调试，后台返回
也保持开屏。Release 忽略该参数。App 模块名为 CubeginApp，避免与 SDK Cubegin
在大小写不敏感的文件系统中冲突。

## 主导航

AppTabsView 使用系统原生 TabView，三个 Tab 共享同一份 TimerModel。iPhone 首页不创建
NavigationStack，也没有品牌工具栏，避免顶部额外占位；iPad 所有窗口宽度都保留 NavigationStack，
并显式显示 navigationBar，让系统为窗口控制按钮保留顶部空间，避免紧凑窗口中遮挡项目菜单。
仅将无背景训练按钮放在顶部右侧，项目菜单始终放在内容顶部下一行居中，避免挤压 Tab 栏。
成绩和设置各自拥有
NavigationStack，设置页使用 inline 紧凑标题，成绩根页面隐藏标题，详情保留系统返回导航。
切换页面不重新生成打乱。首页使用历史四色标志，成绩和设置使用
SF Symbols；系统 Tab 的三个图标使用 28pt 画布，SF Symbols 按当前屏幕比例渲染为模板图像，
避免系统符号配置覆盖指定尺寸。Tab 只显示图标，页面内 Label 仍显示标题。
iPhone 横屏隐藏系统底栏，在右侧用 52pt 的 Liquid Glass 竖栏切换同一个 TabView。
计时首页的页头、成绩各视图和设置卡片共用左右边界：无开孔的左侧留 44pt，开孔在左时在安全区内再留 16pt；右侧内容距导航胶囊 16pt。
右侧无遮挡时，竖栏外缘距屏幕右边 21pt，和 iPhone 17 Pro 竖屏原生 Tab 栏到底边的实测距离一致。
灵动岛位于右侧时，竖栏贴齐右侧安全区。
每个按钮保留 44pt 点击区、辅助功能名称和选中状态。开表时右栏淡出，
原侧栏区域可点按停表。成绩多选时也隐藏导航，露出批量操作栏。
iPhone 竖屏和 iPad 的导航位置、材质及选中指示由系统提供。

成绩页与首页共享项目和训练状态，复用 EventPicker 与 TrainingButton，按 iPad size class
沿用首页的 iPad 导航栏规则。iPad 常规宽度下，分组、项目、视图单排显示，项目居中，分组和视图分别靠两侧页面边距，不限制为 880pt；紧凑宽度的项目和训练按钮进入导航栏，iPhone 使用两行控件。成绩页根页面不显示「成绩」标题，
分组与视图两个菜单左右对齐。iPhone 第一行保留项目和训练按钮原有布局与点击区域，不额外调整图标与胶囊的视觉对齐。成绩与统计都使用当前分组。成绩类型选择器以单次开头并默认选中单次，后面显示达到条数门槛的滚动平均类型。iPhone 横屏统计将分组和视图按钮固定在顶部，内容滚过按钮背后时由系统柔和渐隐。练习量按可用宽度分列，最后一行从第一列排起，日期与次数在各自格内居中。ao 去掉两端各 5%（向上取整），DNF 按最差处理；
保留部分含 DNF 则平均为 DNF，样本不足显示 N/A。+2 先计入单次再参与统计。
单次成绩列表在 iPhone 竖屏也固定分组和视图按钮，列表滚到按钮背后时使用同样的渐隐。

统计在同一滚动页面依次展示概要、图表和练习量。图表类型、范围和平均线筛选跟随图表，位于概要下方。iPhone 横屏为右侧导航预留独立列。图表用图标切换趋势与时间分布，默认显示最近 100 次有效成绩的趋势及达到条数门槛的全部平均线。范围菜单显示「全部成绩」或当前次数，只提供有效成绩数达到的档位。趋势图保留所选窗口内的 DNF 断点。底部按固定配色显示图例，「平均线」菜单标题固定，可逐条或批量开关平均线。横轴与成绩列表使用同一组内序号，绘图区内的纵向拖动可滚动页面。趋势图中的单次 DNF 保留序号，滚动平均复用现有滑动窗口计算并读取视窗前所需的成绩。纵轴始终包含所选成绩范围的全部用时。当纵轴有很长的区间没有单次或平均值时，图表自动缩短这段空白。时间分布用竖柱展示有效成绩，横轴为用时区间，纵轴为次数。趋势和分布共用随宽度调整的图表区域。分布按等宽区间统计，并合并两端的少量极值。相邻空桶合并为一行，首尾空桶省略。

打开图表后才在后台排序、计算平均及分桶。成绩快照未变时复用排序和各类型已计算的平均序列。大量单次按绘图区宽度生成最小/最大值带，平均线在全量视图按桶汇总，遇到缺失值断线。范围、视图或快照变化会取消旧任务。
单次成绩使用原生 List 按需创建行，以成绩 UUID 保持身份，按日期倒序显示；组内序号从总数递减至 1。单行仅显示序号、计时和日期，最小行高 44pt。向左滑动在右侧显示 32pt 正圆红底、白色垃圾桶图标的删除按钮（与分组共用图标绘制），保留辅助功能名称，禁用整行划到底直接删除；点击按钮后二次确认，按成绩 UUID 原子持久化删除并更新各视图统计。长按一条成绩进入多选并选中该条，按住后上下拖动可连续选择起点到手指所在行的范围；靠近列表上下边缘自动滚动，回拖收缩本次范围并保留先前选择。手势通过 UIKit 长按识别器接入原生 List，普通滑动仍滚动列表。支持逐条勾选、全选、取消全选、批量移动与批量删除。多选时左上角项目入口改为全选，分组/视图/训练入口暂时禁用，底部导航隐藏并替换为居中的紧凑玻璃操作栏（已选数量靠左，右侧依次为移动、删除、关闭图标）。移动面板只列当前项目其他分组，可在面板内新建分组而不切换源分组；移动只更新 groupID，保留成绩 UUID、计时、罚时、日期和打乱，一次性持久化，完成后退出多选。批量删除同样二次确认并一次性持久化。切换分组或视图退出多选。日期按本地时区、公历判断：今天显示 HH:mm，本年其他日期显示 MM-DD，其他年份显示 yyyy-MM-dd（使用日历年而非周年）。+2 成绩包含两秒罚时并在末尾显示「+」。
设置页按通用、成绩和关于分组。通用设置提供启动延迟滑块、语言选择和主题选择。
首次启动匹配系统首选语言中受支持的简体中文或 English，否则使用 English。
语言和主题偏好保存在 AppStorage，通过环境 locale 和 preferredColorScheme 传给各页。

## 打乱选择

iPhone 首页左侧的无背景项目按钮打开系统 popover。右侧是哑铃按钮和暂作展示的 Cross 闪光图标，iPad 工具栏也采用相同顺序。
项目列表宽 300pt、高度上限 400pt，横屏空间不足时随弹层缩短，保留列表自身滚动。
iPad 常规宽度（原生 TabView 顶部导航布局）项目菜单单独一行居中，哑铃按钮位于顶部
工具栏右侧并隐藏系统共享背景。紧凑宽度把小号菜单放在原生工具栏前侧，由系统安排在窗口控制按钮右边，训练图标位于同一行右侧。
