# App Store 商店资料

在每次提交前核对仓库草稿与 App Store Connect，保存实际送审的版本。资料有变动时同步更新。

| 资料 | 保存方式 |
| --- | --- |
| 描述、关键词、推广文字和审核说明 | 按商店语言保存并标明实际提交的版本。版本更新说明从[中文](../../CHANGELOG_ZH.md)及[英文](../../CHANGELOG.md)更新记录提炼。 |
| 支持、营销和隐私政策链接 | 保存实际填写的公开 URL，送审前从外网打开验证。 |
| 截图 | 保存实际上传的原始图片，按语言和设备分组，记录尺寸、上传顺序及对应候选。主画面使用真实 App 界面，演示数据使用测试样例。 |
| 价格、地区、年龄分级、内容权利、出口与地区合规、隐私 | 保存本次选择和依据。App 功能、生产 SDK 配置或渠道要求变化时重新核对。 |

审核联系人的私密字段、登录凭据、私钥和签名文件由 App Store Connect 或凭据存储管理。商店截图属于发布素材，由商店后台分发。
