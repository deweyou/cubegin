# Android SDK

[English](README.md) · [中文](README_ZH.md)

Use `io.github.deweyou:cubegin` from Kotlin for scrambles, puzzle state, solving, diagrams, and playback. The AAR supports API 23 and later on arm64-v8a, armeabi-v7a and x86_64. The build stages the package in a local Maven repository.
