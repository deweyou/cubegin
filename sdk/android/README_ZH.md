# Android SDK

[![English](https://img.shields.io/badge/English-blue)](README.md) [![中文](https://img.shields.io/badge/%E4%B8%AD%E6%96%87-blue)](README_ZH.md)

Kotlin 可通过 `io.github.deweyou:cubegin` 使用打乱、魔方状态、求解、展开图和回放。AAR 支持 Android API 23 及以上版本，包含 arm64-v8a、armeabi-v7a 和 x86_64 原生库。构建产物会写入本地 Maven 仓库。
