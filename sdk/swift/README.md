# Swift SDK

[English](README.md) · [中文](README_ZH.md)

Use the `Cubegin` Swift Package product to generate scrambles, evaluate states, solve supported puzzles, and render diagrams or playback frames. It supports iOS 15 and macOS 12 or later. The local XCFramework includes iOS arm64, simulator arm64/x86_64, and macOS arm64.
