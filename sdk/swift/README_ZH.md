# Swift SDK

[![English](https://img.shields.io/badge/English-blue)](README.md) [![中文](https://img.shields.io/badge/%E4%B8%AD%E6%96%87-blue)](README_ZH.md)

通过 Swift Package 的 `Cubegin` 产品生成打乱、计算状态、求解受支持的魔方，以及渲染展开图和回放帧。支持 iOS 15、macOS 12 及以上版本。本地 XCFramework 包含 iOS arm64、模拟器 arm64/x86_64 和 macOS arm64。
