---
name: patch
description: 修复 Cubegin App 的已上架版本，或继续该补丁的送测、提审和上线回合。需要从对应平台实际发布的源码开始。
---

读取 [App 发布规范](../../../docs/app-releasing.md) 和目标平台的发布手册。已有候选时先恢复其进度。

1. 确认要修什么、影响哪个平台和渠道。核对正式 tag 与实际商店 build，推荐最新适用的线上基线和下一补丁号。等用户确认后从该 tag 切补丁分支。
2. 复现、修复并验证。展示相对基线的 diff 摘要、验证结果和中英文用户说明，范围确认后再出包。
3. 补丁分支有改动并推送后，创建指向 `main` 的 Draft PR。沿用共享规范登记候选、送测、提审和按状态持续推进。补丁上线前的返工在原分支升 build。
4. 等商店审核通过并确认上线，按实际 build 打正式 tag，再将范围吻合的 Draft PR 转为待审核并回合。若后续候选也受影响，将修复同步到对应发布分支并重新验收。
